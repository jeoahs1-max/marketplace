Guide JEOAH — Quoi mettre dans la case « Votre ID/Lien de base » ?

  • Amazon : uniquement votre Tracking ID Amazon Associates (ex. jeoahs-20, sans écrire StoreID:).
  • Shein : dans votre espace affilié Shein (Mon compte), copiez uniquement le numéro sous votre nom (ex. 4715984168, sans # ni texte).
  • AliExpress : sur portals.aliexpress.com → Compte → ID de suivi, copiez votre Tracking ID (souvent le mot default ou un nom personnalisé — ce n'est pas un chiffre).
  • Temu / Walmart / eBay : copiez votre ID ou lien partenaire depuis votre espace affilié. Laissez vides les plateformes que vous n'utilisez pas.
